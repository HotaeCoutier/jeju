🌴 제주 가족여행 스마트 가이드 앱 (Jeju Family Trip Planner)

7월 장마철 소나기도 걱정 없는, 우리 가족의 안심 제주 여행 메이트! > 실시간 제주도 지역별 날씨와 날씨 맞춤형 유연한 일정표, 제주 40대 엄선 맛집 지도 및 AI 여행 가이드 비서까지 하나의 모바일 최적화 웹앱에 담았습니다.

📸 핵심 기능 소개

1. ☀️ 실시간 제주 5대 거점 날씨 연동 (Open-Meteo API)

제주시(북부), 서귀포시(남부), 성산읍(동부), 애월읍(서부), 한라산(중앙) 총 5개 핵심 거점의 실시간 날씨 및 기온, 풍속을 실시간으로 가져옵니다.

한라산 고도에 따라 완전히 판도가 다른 제주 날씨를 직관적인 카드로 즉시 진단하세요!

2. 🌧️ 스마트 날씨 토글 일정표 (3박 4일)

화창한 날 코스 ☀️: 에메랄드빛 바다 산책과 수목원, 인생 선셋을 마주하는 아웃도어 동선.

비 오는 날 코스 🌧️: 몰입형 미디어아트(아르떼뮤지엄, 빛의벙커), 아쿠아플라넷, 아케이드 지붕이 있어 비를 맞지 않는 매일올레시장 및 우천 시 더욱 매력적인 비자림 숲길 힐링 피톤치드 코스로 단 1초 만에 전환됩니다.

3. 🍱 제주 4대 권역 엄선 맛집 & 카페 40선 (New!)

제주시, 서귀포, 성산/동부, 애월/서부 권역별로 각각 10곳씩, 총 40곳의 보물 같은 로컬 맛집과 뷰 카페를 한곳에 정리했습니다.

타겟팅 메타 정보: '부모님 만족', '아이 동반', '웨이팅 필수', '포장 특화' 등 유용한 가족 마크 표기.

방문 꿀팁 가이드(예: 테이블링 예약, 포장 꿀팁, 시그니처 메뉴 등) 제공.

4. 🤖 실시간 AI 제주 여행 비서 (Gemini API)

"갑자기 비가 오는데 중문 근처 실내 놀이터 있을까?", "어르신 모시고 가기 좋은 깔끔한 갈치 전문점은?" 등 돌발 상황에 즉시 대답하는 내 손안의 AI 비서.

5. 🎒 우리 가족 캐리어 체크리스트

면허증, 렌트카 예약 확인서부터 모기기피제, 우비/우산 등 장마 대비 소모품까지 터치만으로 체크하고 완수율을 실시간으로 확인하는 스마트 서포터.

🛠️ 기술 스택 및 오픈 API 정보

Frontend: HTML5, Tailwind CSS, Font Awesome 6.0

Weather API: Open-Meteo API (무료, 별도 키 불필요)

AI Engine: Google Gemini Pro (gemini-2.5-flash-preview-09-2025)

Deployment: GitHub Pages / Single-file Web App

🚀 시작하기 & 사용 방법

본 프로젝트는 의존성 설치가 필요 없는 Single HTML File로 개발되어, 브라우저가 있는 디바이스라면 어디서든 즉시 작동합니다.

본 저장소를 Clone 받거나 index.html 파일을 다운로드합니다.

git clone [https://github.com/your-username/jeju-family-trip.git](https://github.com/your-username/jeju-family-trip.git)


스마트폰 및 PC 브라우저에서 index.html을 즉시 열어 사용합니다.

AI 비서 활용 안내:

index.html 내부의 const apiKey = "" 부분에 사용 중이신 Google Gemini API Key를 발급받아 입력하시면 완벽한 실시간 대화형 AI 비서를 구동하실 수 있습니다.

📱 모바일 최적화 레이아웃 안내

모바일 전용 뷰포트(<meta name="viewport" content="...user-scalable=no">)를 설계하여 모바일 웹 브라우저 및 홈 화면 앱 바로가기 등록 시 네이티브 앱 같은 뛰어난 슬릭감과 높은 가독성을 제공합니다.

하단 탭 바 터치 및 모바일 제스처 최적화를 통해 부모님도 쉽게 쓸 수 있는 직관적인 UI/UX를 보장합니다.
